# 둥둥 (dungdung) — 잡념 처치소

머릿속에 둥둥 떠다니는 생각을 도트풍 몬스터로 꺼내 처치하는 앱.
힐링이 아니라 빈정 — 관리가 아니라 비우기. [ilta](../ilta)가 "할일을 관리하는 RPG"라면,
둥둥은 "할일이 되기 전의 카오스를 청소하는 전처리기".

## 루프

1. **쏟아내기** — 머릿속 거 다 적기 (한 줄 = 잡념 하나)
2. **둥둥** — 잡념이 몬스터가 되어 방을 떠다님
3. **심판** — 몬스터 탭 → 할일 / 걱정 / 잡념 (3버튼, 우선순위 없음)
4. **처치** — 할일은 2분짜리 행동으로 쪼개기(번개몬), 걱정은 예언 상자에 봉인(예언몬), 잡념은 분쇄(찌꺼기몬)
5. **오늘의 하나** — 지금 할 것 카드 한 장만

## 몬스터

| 몬스터   | 정체                          |
| -------- | ----------------------------- |
| 둥둥몬   | 아직 판정 안 된 잡념          |
| 예언몬   | "~~이럴 것이다" 추측 → 봉인   |
| 벽돌몬   | 무거운 할일 → 쪼개기          |
| 미뤄몬   | 방치된 할일 (살찜)            |
| 찌꺼기몬 | 쓸데없는 생각 → 분쇄          |
| 메모몬   | 기억해둘 것 → 보관            |
| 번개몬   | 쪼갠 첫 행동 조각 → 즉시 처치 |

## 개발

